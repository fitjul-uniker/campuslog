# Recommendation Page De-AI Polish Design

> 2026-07-26 최종 사용자 결정: 이 문서의 `추천 기록` 아이콘 제거·우측 자체 너비 변경은 적용하지 않고 기존 History 아이콘·ghost 링크·반응형 배치를 유지한다. 사용자 행동 중심 문구와 16px 무그림자 표면 변경만 유효하다.

## 작업 목적

`/recommend`가 범용 AI SaaS 템플릿처럼 보이는 인상을 줄이고, CampusLog 사용자가 다음 행동을 빠르게 이해하도록 헤더 액션, 안내 문구, 큰 표면의 시각 밀도를 정리한다.

## 승인된 방향

- 적용 범위는 `/recommend` 한 화면으로 제한한다.
- 추천 로직, 저장, API, 이미지 첨부, 추천 결과 데이터 구조는 변경하지 않는다.
- 다른 화면에서 사용하는 공용 `EmptyState`와 카드 시스템의 기본 표현은 유지한다.

## 화면 설계

### 1. 추천 기록 액션

- 데스크톱에서는 제목 영역 오른쪽에 44px 높이의 중립 보조 버튼으로 표시한다.
- `History` 아이콘을 제거하고 `추천 기록` 텍스트만 사용해 장식성 아이콘 수를 줄인다.
- 모바일에서 헤더가 세로로 바뀌어도 전체 폭을 차지하거나 가운데 떠 있지 않게 오른쪽에 맞춘다.
- 키보드 focus-visible과 기존 `/recommend/history` 이동은 유지한다.

### 2. 사용자 중심 문구

- 페이지 설명은 `지원 문항이나 JD에 어떤 경험을 쓸지 고민될 때 활용해 보세요.`로 변경한다.
- 완료 경험과 진행 활동이 모두 없는 경우:
  - 제목: `추천에 사용할 경험이 아직 없어요`
  - 설명: `새 활동을 시작해 기록을 쌓거나, 이미 끝난 활동을 바로 등록해 주세요.`
  - 주요 행동: `활동 추가`
  - 보조 행동: `과거 활동 기록하기`
- 완료 경험은 없지만 진행 활동이 있는 경우:
  - 제목: `진행 중인 활동을 경험으로 정리해 주세요`
  - 설명: `쌓아 둔 기록을 확인하고 완료 경험으로 정리하면 추천에 활용할 수 있어요.`
  - 주요 행동: `진행 활동 확인하기`
  - 보조 행동: `과거 활동 기록하기`
- 한 화면에서 `AI`를 반복 설명하지 않고, 기존 H1과 전역 메뉴만으로 기능 맥락을 전달한다.

### 3. 카드·아이콘·그림자 절제

- 추천 빈 상태에서는 책 아이콘과 아이콘 컨테이너를 제거한다.
- 빈 상태는 중앙 정렬된 대형 카드에서 왼쪽 정렬된 작업 안내 표면으로 바꾼다.
- 빈 상태의 최소 높이를 줄이고, 모서리는 16px, 표면 그림자는 제거한다.
- `/recommend`의 입력·결과·로딩 표면에도 페이지 한정 16px 모서리와 무그림자 스타일을 적용한다.
- 파일 Gallery, 입력 경계, 오류 Alert처럼 상태와 조작을 구분하는 내부 경계는 유지한다.

## 반응형

- 860px 이하에서 추천 기록 액션은 헤더 오른쪽에 자체 너비로 유지한다.
- 640px 이하에서 빈 상태 행동은 기존처럼 세로 배치하되 왼쪽 정렬과 전체 폭 터치 영역을 유지한다.
- 390×844에서 가로 overflow가 없어야 한다.

## 접근성

- 추천 기록과 두 빈 상태 행동은 의미가 드러나는 텍스트를 유지한다.
- 모든 링크는 최소 44px 조작 영역과 focus-visible을 유지한다.
- 빈 상태의 제목과 설명 읽기 순서는 바꾸지 않는다.
- 색상만으로 위계를 표현하지 않고 border, 크기, 굵기와 배치를 함께 사용한다.

## 검증

- 구조 테스트로 새 문구, 아이콘 제거, 페이지 한정 스타일을 고정한다.
- 기존 추천 폼과 이미지 첨부 테스트를 함께 실행한다.
- lint, TypeScript, 전체 테스트, `git diff --check`를 실행한다.
- 브라우저에서 `/recommend` 빈 상태를 데스크톱과 390px 모바일 기준으로 확인한다.

- 추천 결과 정보 구조 변경
- 전역 카드, 아바타, 다른 화면의 EmptyState 변경
- API, schema, repository, 사용자 데이터 변경
