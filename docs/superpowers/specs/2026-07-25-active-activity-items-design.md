# 현재 진행 활동 Item 목록 디자인

## 목적

`/dashboard`의 `현재 진행 중인 활동`을 제목 중심으로 빠르게 훑고, 활동 상세로 이동할 수 있게 합니다. ReUI `Item`의 클릭 가능한 목록 행과 trailing action 패턴을 참고하되 CampusLog의 검정·차콜 토큰과 기존 데이터 흐름을 유지합니다.

## 승인된 구조

- 바깥 활동 영역의 제목, 활동 수와 `활동 추가` CTA는 유지합니다.
- 각 진행 활동은 활동 제목과 오른쪽 Chevron을 가진 클릭 가능한 Item으로 표시합니다.
- 삭제는 별도 상시 버튼 대신 44px `···` 메뉴 안에 배치합니다.
- 데스크톱은 2열, 860px 이하에서는 1열로 배치합니다.
- `진행 중` 상태는 섹션 제목과 중복되므로 개별 Item에 표시하지 않습니다.
- 활동 상세 경로, 삭제 확인과 repository 동작은 변경하지 않습니다.

## 상태와 접근성

- Item 링크와 메뉴는 각각 활동명을 포함한 접근 가능한 이름을 제공합니다.
- hover와 `focus-within`은 위치 이동 없이 배경, 테두리와 약한 그림자만 변경합니다.
- Chevron의 짧은 이동은 reduced motion에서 제거합니다.
- 빈 상태, 로딩, 공통 성공·오류 피드백은 기존 계약을 유지합니다.

## 검증

- 상세 경로와 접근성 라벨 단위 테스트
- lint, typecheck, production build와 전체 Node 테스트
- 로그인 `/dashboard` 데스크톱·모바일 배치, 메뉴 열기, 가로 overflow와 콘솔 오류 확인
